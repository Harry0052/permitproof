# Changelog

## 0.1.0 — 2026-11-23

First release candidate.

- Local checklist for two Seattle commercial uses, general retail and general office, in districts NC2 and C1.
- Synthetic parcel snapshot, versioned rule rows, and confirmation categories for ambiguous addresses, multiple designations, overlays, conflicting rules, missing prior use, stale or empty snapshots, and an as-of date outside coverage.
- Command-line validate, check, and demo flows with JSON, HTML, and text reports.
- Every report sets `approval` to false.
